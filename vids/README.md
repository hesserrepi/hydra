# vids

Videos that play along with a song (`uboa()`, `song.video()`; see
`public/extensions/effects/hydra-song.js`). `npm run dev` serves this folder at
`vids/<name>`. The video files themselves are not committed to git (see
`.gitignore`), so copy them here on each computer.

- `uboa.mp4`: played by `uboa()`
